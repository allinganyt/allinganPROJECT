# Muzik Player 🎵

Музыкальный веб-плеер в стиле Fluent / Liquid Glass. by **allingan** & Gemini.

## Версии
| Файл | Описание |
|---|---|
| `muzik-player.html` | Оригинальная версия (Tailwind CDN) |
| `muzik-player-v1.html` | v1 — Windows Fluent Glass, Tailwind CDN |
| `muzik-player-v2.html` | v2 — Liquid Glass, чистый CSS |
| `muzik-player-v3.html` | v3 — адаптивная (ПК/телефон), поиск по словам, визуализатор |

## v3 — что умеет
- Адаптивная вёрстка: ПК, телефон вертикально и горизонтально
- Поиск по словам: SoundCloud (реальные результаты, без ключа) и YouTube (через бесплатный API-ключ в настройках ⚙ или Piped-зеркала)
- Прямые ссылки YouTube / SoundCloud вставляются сразу
- Плейлист сессии, удаление треков, громкость
- Визуализатор: реальный спектр для локальных аудиофайлов (Web Audio API), ритмичная анимация для стримов

## Как запустить
Просто открой `muzik-player-v3.html` в браузере. Всё клиентское, сервер не нужен.

## Заметки
- Поиск SoundCloud использует публичные client_id веб-плеера; если их отзовут — обнови `SC_CLIENT_IDS` в коде.
- Пауза/реальный спектр для YouTube/SoundCloud iframe ограничены кросс-доменными правилами браузера.
